# Hello — Number Guessing Game 🎯

My very first Python project! A simple command-line game where the computer
picks a random number between 1 and 100 and you try to guess it.

## How to Run

Make sure Python is installed, then run:

```bash
python guess.py
```

## How to Play

1. The computer picks a secret number from 1 to 100
2. Type your guess and press Enter
3. You get a hint: too high, too low, or correct
4. Keep guessing until you win — fewer tries = better score!

## What I Learned

- Variables and loops (`while`)
- Conditionals (`if` / `elif` / `else`)
- User input and type conversion
- Using Python's `random` module
