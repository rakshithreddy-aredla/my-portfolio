# My Website 🌐

My very first website — a personal about-me page built with pure **HTML** and **CSS**. No frameworks, no templates, just hand-written code!

## How to View

**Option 1:** Just double-click `index.html` — it opens in any browser.

**Option 2:** Right-click `index.html` → Open with → your favorite browser.

## What's on the Page

- **About Me** — a short intro
- **My Learning Journey** — skills I'm learning
- **My Projects** — cards showcasing what I've built
- **Find Me Online** — link to my GitHub

## What I Learned

- HTML page structure (`<head>`, `<body>`, `<header>`, `<main>`, `<footer>`)
- CSS styling: colors, fonts, spacing, and layout
- CSS gradients and box shadows
- Linking a stylesheet to an HTML page
- Responsive basics with `max-width` and `margin: auto`
